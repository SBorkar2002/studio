# Taste gate

Use this when the question is **what it should look like**, not how to build it: a new page, a new project direction, a redesign, or her saying it looks generic, junior or "AI".

## The gate

1. **References that get used.** Collect at most 8. For each, write one line: what to steal and which section it goes to. A reference that maps to nothing is dropped. Flag paid or unlicensed sources before using them.
2. **One style tile first.** Palette, type pair, one component, one motion idea, one real content block. In Figma or a single HTML page. Offer 2 or 3 only when the direction is genuinely open.
3. **Her pick, then tokens.** Lock colours, type scale, spacing and radii as tokens. Nothing past the tile is built before she approves it.
4. **Distinct register.** Each project gets its own voice tied to what the product means (Sourced = night gallery, Green Gallery = cute and bubbly, portfolio = pixel chrome with HD work). Check it does not look like her other projects.

## AI-generic ban list

Reject these unless she asks for them:

- Editorial serif + mono "labels" + hairline rules on paper (her top reject).
- Off-white + black type + one orange accent (the "Claude showreel" look).
- Purple-to-blue gradients, glassy blobs, generic 3D clip art, glossy vector illustrations.
- Cards everywhere; stacked identical cards where a story or scrollytelling fits.
- Inter / Roboto / Space Grotesk by default.
- Fade-up-on-scroll for everything; bounce; scale pops.
- Chips and badges as decoration.

## Tools, and when

- `impeccable:impeccable` for critique, audit and polish of anything built. Use product mode for apps and dashboards, brand mode for marketing and portfolio pages.
- `taste-skill:design-taste-frontend` only when setting a **new** direction. It is heavy (about 9k tokens), so not for tweaks.
- `emil-design-eng` and `apple-design` for motion and interaction craft.
- `playground:playground` when a value needs tuning live (easing, spacing, colour).
- DESIGN.md files from VoltAgent/awesome-design-md as reading only; never copy a brand.
